# Coding session 1

Today I try and implement the handler for creating user - basic CRUD operation. The logic was easy, it was just getting the database to run query to insert a row, so it was not a problem. An obstacle I faced was the architecture of my project, I was kind of confused about the imports, and which code should go where. After consulting Gemini, I finally understand that main.go is the entry point of the project, it is the file that imports others, while api, database, auth, config, etc never import main. Those packages can depend on each other, but everything ultimately flows back to main.go

To do dependancy injection, in this case, the Apiconfig that has database in it so the handlers can interact with database, I initialized the struct in api package, pass the struct to main, then create an instance of it in main. My main.go also import database package so it can use .New() method to initialize a list of queries. 

After resolving the architecture problem, my endpoint ran as expected, but i wanted a bit of code refactor so i wont build up technical debt, the fix was major, this was the before code snippet

`
incredibly bad,
1. using the sql.NullString made the request json messy 
2. forgot to return after respondWithError, causing superflous something -> two responses from one request
3. duplicate CreateUser call, duplicate database.CreateUserParams

the fix:
`
func (a *ApiConfig) addUserHandler(w http.ResponseWriter, r *http.Request) {
    // 1. Define local params with pointers for cleaner JSON input
    type params struct {
        Username string  `json:"username"`
        Bio      *string `json:"bio"` 
    }
    
    param := params{}
    if err := json.NewDecoder(r.Body).Decode(&param); err != nil {
        // Return early! 400 because the client sent bad JSON
        respondWithError(w, 400, "Invalid request payload", err)
        return 
    }

    // 2. Data Transformation (The "Mapping" step)
    // Initialize params with the required fields
    dbParams := database.CreateUserParams{
        Username: param.Username,
    }

    // Convert the pointer to sql.NullString
    if param.Bio != nil {
        dbParams.Bio = sql.NullString{String: *param.Bio, Valid: true}
    } else {
        dbParams.Bio = sql.NullString{Valid: false}
    }

    // 3. Single Database Call
    user, err := a.Database.CreateUser(r.Context(), dbParams)
    if err != nil {
        // 500 because the database failed
        respondWithError(w, 500, "Couldn't create user", err)
        return
    }

    // 4. Single Success Response
    respondWithJSON(w, 201, user)
}

`
